# 📱 Harcama Takip V3 - iPhone PWA

Bir iPhone'a kurabileceğiniz ve çevrimdışı çalışan kişisel bütçe takip uygulaması.

## 🚀 Kurulum (iPhone Safari)

1. **GitHub Pages'ten açın:**
   - https://bmzhzkj56g-tech.github.io/harcama-takip/

2. **Ana Ekrana Ekle:**
   - Safari'de "Paylaş" butonuna tıklayın
   - "Ana Ekrana Ekle" seçeneğini seçin
   - Adı onaylayıp ekleyin
   - 📱 Ardından uygulamayı ana ekranından başlatın

3. **Özellikler:**
   - ✅ Çevrimdışı çalışır
   - 💾 Otomatik olarak kaydeder
   - 📊 Günlük harcama limitini hesaplar
   - 🎨 Dark mode arayüz

## 📋 Kullanım

- **Temel Bakiye & Borçlar:** Maaş, nakit ve kart borcu giriniz
- **Sabit Giderler:** Rent, elektrik, su vb. ekleyin
- **Taksitler:** Kredi/taksit ödemeleri giriniz
- **Ek Gelirler:** Ek gelir kaynakları ekleyin

Uygulama otomatik olarak:
- Ayın 28'ine kalan günü hesaplar
- Günlük harcama limitinizi gösterir
- Tüm verileri telefonda saklar

## 💡 İpuçları

- Verileri güvence altına almak için telefon ayarlarında "Dosyaları Uygulama İçinde Sakla" etkin bırakın
- Çevrim içi olduğunuzda otomatik senkronizasyon yapılır
- Eski cihaza taşımak için localStorage veritabanını manuel backup yapabilirsiniz
